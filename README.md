# BATTER'S READ — MVP

スマホ向けバッティングゲームの操作感検証用MVPです。

## 操作
- 球の位置をタップして狙う
- 押している間は指でカーソルを動かせる
- 長押しするほどミート範囲が広がる
- 長押しするほどパワーが落ちる
- 指を離した瞬間にスイング

「球種・コースを絞って早く振れば高火力、見てから対応すれば当てやすいが弱い」というトレードオフを検証します。

## MVP
- 20球
- FAST / CURVE / FORK
- スマホ縦画面向け
- タイミング + 位置でミート判定
- 10 / 30 / 50 / 100点
- 簡易SE / 対応端末で振動


## 3D Geometry Lab
ゲーム本体とは別に、打者視点の幾何を確認する検証ページを用意しています。
