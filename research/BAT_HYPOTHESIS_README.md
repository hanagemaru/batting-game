# 実測手元＋推定バット：スイング比較ラボ (2026-11-15)

## 今回の判断

元候補の Trenev / Tishinov / Ivanov (2024) Fig.1 は
**16枚×2方向**の同一打撃画像で、120fpsで撮影された。
しかし原図（PDF p.4）を再確認すると、個々の写真は掲載画像として小さく、
横からのカメラは純粋な直交側面ではなく斜め投影になっている。
バット先端・グリップの両端を安定して識別するには解像度が足りず、
画像しかない状態で正確な絶対3D座標を算出することは見送る。

- Fig 1: https://jtambg.eu/papers/2024/JTAM2024_4_511-524.pdf#page=4
- 方法: 2カメラ、120fps、シャッター1/2000秒、独立校正。
- **画像の16番号だけから映像の全時間を確定しない**。
- 本番組み込み不可の具体的な3D点列を「測定データ」として作らない。
- 二次利用権を確認できないため原図の画像をGitHubにコピーしていない。

### 動作仕様

1. 身体・腕・手はCMUデータのオリジナル時系列（約120Hz）。
2. バットのグリップ位置は左右の手の中点を利用する代理変数。
3. 構えから推定接触フレームまで、バット軸は球面ベジェ曲線で連続回転。
   グリップとは独立した姿勢仮説として明示している。
4. 接触後のバット軸は接触直前の回転面内を連続して振り抜く。
   バット先端の絶対軌跡はグリップの動きも含むため厳密な平面ではない。
5. グリップ・先端・芯を1本の剛体バットとして計算。長さ86.4cmを固定。
6. 3視点の再生で同時確認し、4種類の接触角度とモデル上昇角を比較。
7. **現行ゲームの40ms操作応答は今回変更していない**。
   既存ゲームの当たり判定・球種・カメラにも接続しない。

### 計算検証（4例×3つの上昇角）

- **12条件、計1692姿勢**を確認。
- バット長: 0.864mに浮動小数点誤差内で一致。
- 接触後のバット軸の回転面からの逸脱: 約1.5e−16以下。
- 接触直前・直後の先端速度変化: 速度比約0.75%以下。
- 仮説モデルの接触時のバット先端速度: 約22m/s。
  **これは実測速度ではなくモデルから得られた計算値**。
- 実測した2つの手位置には接触フレームで約24cmの距離があり、
  中点が実際のバット握り位置と一致しているとは限らない。
- 3DビューアのJavaScript構文・入力DOM参照チェック通過。
- **ユーザーのiPhone Safari実機表示は未検証**。

### 次の判断基準

プレビューで体の動きと推定バットの大きな不整合が見られたら、
バットの向きを微調整するのでなく、グリップの推定法を見直す。
CMUにはバット計測値がないので、今後は商用利用できる
同時刻・2方向の高fps動画、もしくは独立に取得した
バットのマーカー軌道で検証する。

この段階では**主な成果は比較インフラ**であり、
「実測のバット軌道を得た」「自然なバット軌道が完成した」とは主張しない。
